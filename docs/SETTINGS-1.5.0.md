# 1.5.0 设置说明

在「选项 → 视频设置」新增两个项目，保存到客户端的
`config/endfieldmenu-client.toml`。升级时保留用户已有的其他参数。

| 设置 | 默认值 | 行为 |
|---|---|---|
| 菜单分辨率 | 跟随窗口 | 只改变 HTML 网页，不改变世界、窗口或游戏 GUI 缩放 |
| 低内存模式 | 关闭 | 隐藏约 60 秒后也关闭菜单浏览器；重开需要重新加载 |

菜单分辨率顺序为：跟随窗口、1280×720、1920×1080、2560×1440、3840×2160。
固定预设是最大包围尺寸；按窗口宽高比等比适配，设置按钮同时显示实际尺寸。
例如正方形窗口选择 1920×1080，会使用 1080×1080 网页；不会拉伸。
网页末尾另有不可见的 64 像素元数据区，不计入显示尺寸。

不会自动调低画质。分辨率低于窗口时更省捕获、解码和上传成本，但文字会变软；
高于窗口时会增加资源消耗。4K 选项提供手动选择，不代表 4K 可稳定 60 FPS。

关闭菜单立即停帧流、清队列、释放解码原生缓冲；约 60 秒后释放网页 GPU 纹理、
共享帧接收缓存、地形和磨砂目标。默认保留 DOM/浏览器，缩小其隐藏 viewport；
浏览器自身仍可能保留数百 MiB 的缓存，不保证返回初始占用。
低内存模式在同一超时销毁本菜单浏览器。退出世界释放本模组会话。

高级配置：

| TOML 参数 | 用途 |
|---|---|
| `menuResolution` | 0=窗口，1=720p，2=1080p，3=1440p，4=2160p |
| `lowMemoryMode` | 浏览器闲置回收 |
| `losslessCapture` | true 使用真实 alpha 的透明 PNG；明显慢于默认 JPEG，切换后重新进入世界 |
| `directCapture` | true 连续浏览器合成帧；不可用时回退 AUI 捕获 |
| `frostRadius` / `frostTint` / `frostGrain` | GPU 实时磨砂半径、灰黑色调、细颗粒 |
| `radius` / `sampleStep` | 真实已加载地形范围和采样间距 |
| `contourInterval` / `heightScale` | 等高距与高度夸张 |
| `contourAltitudes` / `contourColors` | 五个绝对海拔锚点与颜色，默认 63/96/144/200/256 |

默认 JPEG 为质量 95，shader 近似移除背景色；头像四边形内保留真实绿色。
元数据位于屏幕外，不再覆盖左上方图像。其他绿色素材和半透明边缘仍可能有
近似合成误差；需要真实 alpha 时手动选 PNG。

独立 `endfield_codec.dll` 随模组提供并按 SHA256 提取到实例
`endfield/native/<hash>/`。不修改 AUI JAR/DLL。DLL 仅加速完整图像解码，
并非共享 GPU 纹理。加载失败时使用 Windows WIC；帧通道失败时回退 AUI。
