# 1.4.2 实时磨砂背景验证

问题：默认 JPEG 网页背景保存上一张世界截图。浏览器复用后，新截图还需 GPU 回读、PNG 编码、状态轮询和图片加载；运行中的世界背景每秒才刷新一次，打开时会看见旧视角。

1.4.2 删除上述背景截图链路和 backdrop.png 接口。每帧将当前世界纹理做双向模糊、灰黑调色和颗粒处理，结果保留在独立 GPU 纹理；合成网页时直接采样这张本帧纹理。新网页尚未就绪时，屏幕显示的也是当前帧原生磨砂背景。HTML、AUI 输入、原生地形和 900ms / 520ms 动画继续沿用。

默认 JPEG 不提供 alpha，网页使用保留的绿色背景，合成 shader 在显示前移除其覆盖量，再填入实时磨砂世界。元数据与网页在同一完整帧中提交，不会故意展示绿色占位。此方法是近似透明恢复：绿色 UI 图案或自定义绿色头像可能受影响，JPEG 边缘也可能有少量色差；losslessCapture=true 使用真实 alpha，颜色更准确但捕获较慢。地图仍使用独立的洋红区域及原生纹理，海拔线条不经过 JPEG。

## 实际运行

Minecraft 1.21.1 / NeoForge 21.1.251 / AUI 1.2.8；1920×1080 窗口，后续缩放至 1280×720；VSync 关闭、游戏上限 120。仅使用独立 endfield-qa 世界，不改动外部游戏实例。

专项验证全部通过：

- 关闭菜单，旋转玩家视角 150°，重新打开；GPU 背景纹理指纹变化，复用同一浏览器。
- 关闭暂停后，背景渲染计数在四秒内增加超过 100 次，更新不依赖网页 FPS。
- 保持菜单打开，再旋转视角 90°，GPU 背景纹理随世界变化。
- 窗口切至 1280×720 后 GPU 目标与菜单正常绘制。
- 最后 Esc 正常完成收起并关闭。

测试中的纹理回读仅用于 QA 对比指纹，不属于发行版背景链路。

首开样本网页约 63.35 FPS，热重开首帧 122.40ms；结尾混合尺寸样本网页约 62.15 FPS，P95 30.47ms，游戏约 117 FPS。以上不代表稳定锁定 60 FPS。完整数据见 [metrics-1.4.2.json](metrics-1.4.2.json)，专项日志见 [runtime-background-1.4.2.log](runtime-background-1.4.2.log)。
