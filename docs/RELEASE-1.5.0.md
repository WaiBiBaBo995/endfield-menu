# Endfield Menu 1.5.0

适用于 Minecraft 1.21.1、NeoForge 21.1.251+、Windows x64、Java 21。
前置 ApricityUI **1.2.8+** 和 WebView2 Runtime。服务端无需安装。
升级时移除旧版 Endfield Menu。

## 变更

- 保留原 HTML/SVG 排版和 AUI 输入，地形与实时磨砂使用原生 shader。
- 新增视频设置中的菜单分辨率与低内存模式。
- SIMD 图像解码、完整帧缓冲复用、关闭停止捕获并清理队列。
- 闲置约 60 秒释放菜单纹理、地形与磨砂缓存；低内存模式同时关闭浏览器。
- 修复绿色头像被去除、元数据覆盖可见画面的问题。
- 保留 900ms 展开 / 520ms 收起、玩家扫描光与海拔渐变等高线。

## 验证与限制

17 项单元测试、46 项输入回归、27 项缓存及分辨率专项通过。
完成 100 次开关、10 次世界往返和 15 分钟观察。

配对测量解码耗时下降约 40%，但整体性能并非全面提升，稳定 60 FPS 尚未达成。
1080p / 1440p 网页帧率约 64 / 57 FPS。专属浏览器峰值约 1.83 GiB，最终闲置
约 347 MiB；低内存模式可在超时后回收专属浏览器。

默认 JPEG 为近似透明合成；PNG 保留真实 alpha，但明显更慢。
AUI 1.2.8 是当前实测版本，更新版本需要保持相关内部接口兼容。
完整测量口径、限制和截图见仓库 `docs/VALIDATION-1.5.0.md`。
